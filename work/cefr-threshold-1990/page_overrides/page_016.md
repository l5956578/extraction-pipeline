## 1 The objective: levels of specificity

The objective will be formulated in three stages, or at three levels of specificity:

1. General characterisation
2. Extended characterisation
3. Specification

The *general characterisation* is meant as an overall description for rapid orientation.

The *extended characterisation* is a detailed description for all potentially interested parties, including the learners themselves.

The *specification* is a fully detailed description meant for course designers, curriculum planners, test constructors, etc.
