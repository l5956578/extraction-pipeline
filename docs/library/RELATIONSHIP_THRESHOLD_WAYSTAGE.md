# Relationship map — Threshold 1990 ↔ Waystage 1990

**Authors:** Same tradition (van Ek & Trim; Waystage origins with Alexander / *Follow Me*).  
**Editions in library:** Cambridge University Press for Council of Europe, revised/corrected **1998** printings of the **1990** revisions.

---

## 1. One-sentence relationship

**Waystage is a coherent early objective cut from the Threshold model; Threshold is the freer, fuller social/travel independence objective on the same chassis.**

They are a **complementary pair**, not competitors and not CEFR level labels.

---

## 2. Shared DNA (do not invent artificial differences)

| Shared element | Meaning for use |
|----------------|-----------------|
| Functional/notional model | Functions + general notions + specific notions/themes |
| Objective ≠ syllabus | Users adapt, add, subtract |
| Adult / general English orientation | Social contact + everyday business when abroad |
| Components beyond phrase lists | Texts, writing, sociocultural, compensation, learning-to-learn, degree of skill |
| Pronunciation & grammar appendices | Supporting apparatus (intonation needs visual fidelity) |
| Multi-language family | Parallel Threshold/Waystage-type objectives exist for many languages |

---

## 3. Distinctions that matter

| Dimension | Waystage 1990 | Threshold 1990 |
|-----------|---------------|----------------|
| **Learning load (authors’ estimate)** | ~**180–200** hours | ~**375** hours (~2×) |
| **Freedom of operation** | Many purposes served, **less freedom** than Threshold | **Reasonable independence** in social/travel life |
| **Inventory size** | **Rigorous selection** from Threshold | Fuller function/notion sets |
| **Primary use case** | Early general ability; incentive to continue | Main “common needs” adult objective historically |
| **Historical project role** | Intermediate for *Follow Me* toward Threshold | Original 1975 Threshold Level lineage |
| **CEFR rough adjacency** | **A1–A2** region (job.json) | **B1** region (job.json) |
| **Chapter order** | Verbal exchange after sociocultural | Verbal exchange before texts/writing/sociocultural |
| **Themes chapter title** | “Themes and specific notions” | “Specific notions” (themes embedded) |

---

## 4. Which is primary for which purpose?

| Purpose | Prefer first | Then |
|---------|--------------|------|
| Design **early** adult English objectives / survival social English | **Waystage** | Threshold for expansion path |
| Design **independent social/travel** English (pre-CEFR “threshold”) | **Threshold** | Waystage as prerequisite checkpoint |
| Function lists for A-band materials | Waystage ch. 3 | Threshold ch. 7 if richer options needed |
| Function lists for B1-ish materials | Threshold ch. 7 | Companion can-dos for *levelled* descriptors |
| Situation/transaction detail | Threshold extended characterisation | Waystage ch. 1 (compact) |
| Intonation teaching marks | **Either App A via PNG/Vision** | Never trust OCR alone |
| Path design “Waystage → Threshold” | Both — same components enable smooth transition (authors’ claim) | CEFR A2→B1 can-dos for modern reporting |

---

## 5. Complementarity (how they illuminate each other)

1. **Same skeleton, different density** — Teaching one trains the categories of the other.  
2. **Motivation ladder** — Waystage success intended to pull learners toward Threshold.  
3. **Selection principle visible** — Comparing inventories shows what Threshold considers “more than basic.”  
4. **Shared strategy/sociocultural chapters** — Even early objectives include compensation and learning-to-learn (not “grammar only first”).  
5. **Neither replaces CEFR** — Both are **objective specifications with exponents**; CEFR 2001/Companion supply **common reference levels and can-do scales**.

| Query | Strategy |
|-------|----------|
| “Functions for shopping at early level” | Waystage functions + themes; optional Threshold shopping situations |
| “Full exponent set for complaining” | Threshold functions (attitudes/suasion) |

| “Intonation pattern for yes/no” | App A page images |

**Anti-pattern:** Calling Waystage “A1” or Threshold “B1” *as if* they were CEFR descriptor texts.  
**Anti-pattern:** Using only one book when designing a multi-year adult path.  
**Anti-pattern:** Ignoring App A because text extract is empty/poor.
