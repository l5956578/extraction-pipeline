## Book purpose (one paragraph)

Waystage 1990 is an **early, worthwhile communicative objective** for learners who want a **general basic ability in English** but cannot (yet) commit to the full **Threshold 1990** learning load. It is a **rigorous selection from Threshold**, same model and same component types, prioritising **immediate usefulness and widest scope**, while remaining a **station on the way** to Threshold. Estimated load **~180–200 hours** (about half of Threshold’s cited ~375). Originally shaped by the **Follow Me** multi-media project’s need for an intermediate objective below Threshold.

## Agent navigation tips (Waystage)

1. **Early A-band “what should they manage in life?”** → Ch. 1 objective description + Ch. 5 themes.  
2. **Function lists lighter than Threshold** → Ch. 3; escalate to Threshold ch. 7 when freer range needed.  
3. **Do not skip strategies** → Ch. 10–11 even at early stage (1990 design intent).  
4. **Intonation** → Appendix A via page images, not text layer.  
5. **CEFR mapping** → Roughly **A2 / strong A1–A2** *objective density*, but always present as **specification inventory**, not as CEFR descriptor scale text.  
6. **Always pair with Threshold** when designing a path from early to independent social English.
