# Vision extract process docs (1990 / 2001 jobs)

**Not** the librarian navigation layer (`docs/library/`).

These files support the **Vision/OCR extract path** for Threshold, Waystage, and CEFR EN 2001 (`scripts/vision_extract/`, `work/<job>/page_overrides/`).

| File | Role |
|------|------|
| ELEMENT_CATALOG_CONTRACT.md | Mechanical QA classes (stitch, vertical bands, page numbers) |
| INTONATION_NOTATION.md | Unicode tone marks for extract quality |
| INTONATION_PAGE_INDEX.md | Pages needing multipass Vision |
| TABLE_INVENTORY_CEFR2001.md | CEFR 2001 table inventory |
| EXTRACTION_STATUS_1990_2001.md | Job/status snapshot for these extracts |
| VISION_PASS_LOG.md | Honest Vision invocation notes |

Librarian: for **content** meaning of tones, read Threshold/Waystage product MD (App A + function exponents). Do not treat this folder as CEFR domain knowledge.
