## Legend used here

| Glyph | Meaning |
|-------|---------|
| `ˈ` | High upright / head (vertical above) |
| `ˋ` | High falling (diagonal above) |
| `ˎ` | Low falling (diagonal below; PDF looks like low “,” stroke) |
| `ˇ` | Falling-rising (v above) |
| `·` | Mid-height secondary stress (rhythmic, non-nuclear) |
| `ˊ` | High rising |
| `ˏ` | Low rising |
| `\|` | Tone-group boundary |

## 1.3.2 correcting a positive statement

e.g. `Vaˈletta is in ˎItaly.`

| Word | Mark |
|------|------|
| No | `ˈ` |
| it | — |
| isn’t | `ˇ` | **fall-rise — not high fall ˋ** |

**MD:** `ˈNo it ˇisn’t.`
